# Changes from Onyx

| Original Onyx | This project adds |
| --- | --- |
| RAG, search, citations and document indexing | Sales-specific knowledge pack to ingest through the same pipeline |
| Agent chat loop and Tool Runner | A documented Custom Action integration for the Sales Copilot API |
| PostgreSQL/SQLAlchemy foundation | Six isolated `sales_*` CRM tables and deterministic seed data |
| Generic Actions/MCP | Typed read/mutation business endpoints and an explicit confirmation field |
| Existing tracing/tool-call UI | Sales calls appear in the existing tool-call trace; no observability platform was recreated |

This is a portfolio-oriented secondary development project. It does not claim that Onyx-native RAG, Agent or UI features were authored here.
