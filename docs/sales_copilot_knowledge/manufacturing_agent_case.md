# Manufacturing knowledge Agent case

A 3,000-person manufacturer had IT and HR teams answering recurring policy, equipment SOP and onboarding questions. The recommended PoC starts with two high-volume knowledge domains, named content owners and a measurable baseline: ticket volume, first-response time, deflection rate and answer acceptance.

The solution uses an indexed enterprise knowledge base for grounded answers, citations for reviewer confidence, and limited tools for approved workflows. Start in a segregated VPC deployment when data residency or network policy requires it. Do not begin with broad write permissions; add actions only after retrieval quality and approval controls are agreed.

Suggested discovery questions: Which questions recur? Which sources are authoritative? Who may access each source? What systems need read-only integration first? What accuracy and deflection threshold defines PoC success?
