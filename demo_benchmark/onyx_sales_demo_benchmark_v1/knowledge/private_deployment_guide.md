# Onyx Private Deployment 技术指南（2026-09，当前版本）

## 支持
- 部署到客户 VPC / 私有基础设施。
- 可使用客户内部模型服务或客户允许的模型 Endpoint。
- 可结合企业 SSO/RBAC 与审计能力。
- 支持客户提供的 GPU 环境。

## 当前限制
- “完全离线 + CPU-only + 无可用本地模型服务”的组合不属于标准支持范围。
- 国密算法适配需要项目级评估，并非标准开箱能力。
- HSM 集成仍为项目化能力，尚未承诺通用 GA。

## 建议
遇到高合规客户应在正式承诺前完成 Technical Assessment。
