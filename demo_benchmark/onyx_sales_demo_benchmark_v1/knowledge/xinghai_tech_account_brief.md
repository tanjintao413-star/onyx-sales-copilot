# 星海科技客户参考资料（2026-09）

## 公司背景
星海科技是一家华东地区大型制造企业，员工约 3,000 人，IT、HR、生产运营部门知识咨询量较大。

## 当前业务目标
- 建设企业知识 Agent，降低 IT 与 HR 重复咨询。
- 希望先做 6–8 周 PoC，再决定是否扩大部署。
- 业务侧希望支持制造业内部知识、设备运维 FAQ、HR 制度与 IT 支持。

## 技术与安全约束
- 业务数据不得离开客户 VPC。
- 不接受将内部文档发送至公共 SaaS。
- 需要与 Azure AD 集成。
- 审计日志至少保留 180 天。
- 客户可提供 VPC 内 GPU 资源。

## 决策角色
- CIO：最终预算负责人。
- IT 架构负责人：技术方案审批。
- HR 数字化负责人：主要业务 Sponsor。
- 安全团队：具有否决权。

## 采购信号
客户认可 RAG + Citation + Tool Calling 的演示效果，但要求补充制造业案例和安全架构说明。
